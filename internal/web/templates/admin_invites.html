Safe lifecycle

How a link is used

  1. Opening the link stores it briefly in an HttpOnly browser cookie.
  2. Submitting setup reserves it so a concurrent signup cannot start.
  3. A failed or timed-out Kite check releases it for another attempt.
  4. A verified account consumes it forever; revocation stops it immediately.
